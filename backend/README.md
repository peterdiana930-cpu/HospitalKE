# HospitalKE - Kenya Hospital Management System 🏥

LIVE LINKS:
- Frontend: https://peterdiana930-cpu.github.io/HospitalKE/
- Backend API: https://hospitalke.onrender.com
- API Docs: https://hospitalke.onrender.com/docs
- Patients JSON: https://hospitalke.onrender.com/api/patients

Features:
- Add Patient (Name, Age, County, Condition)
- View Patients List (4 patients saved online)
- Full Stack: Frontend on GitHub Pages + Backend on Render
- Kenya Counties Support

How to Use:
1. Open Frontend link
2. Add new patient on left form
3. Click Refresh to see in list
4. Data saved online in Render database

Tech: FastAPI + HTML/CSS/JS + GitHub Pages + Render
